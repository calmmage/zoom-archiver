# Security policy

## Report a vulnerability privately

Open this repository on GitHub, select **Security → Advisories → Report a
vulnerability**, and submit a private report. Use that private advisory for
follow-up details and coordinated disclosure; do not describe an unpatched
vulnerability in a public issue or pull request.

If **Report a vulnerability** is unavailable, open an issue asking the maintainers
to enable private vulnerability reporting. Include no vulnerability details in
that issue, and wait for a private reporting channel before sharing them.

Include the affected version or commit, Python version and operating system,
expected and actual behavior, potential impact, and a minimal reproduction using
synthetic data. Remove credentials, access tokens, signed download URLs, account
identifiers, meeting metadata, and recording contents from examples and logs.
Do not attach an archive or its inventory database.

There is no bug bounty program or guaranteed response time.
